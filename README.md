Entry for make.fun's "One Line, One Laugh" bounty: a small deterministic Python program that writes one original funny line (78 characters) to `/output/entry.txt`. The line was written fresh for this bounty — a joke about talking to houseplants, with the punchline landing on the cactus.

Bounty: https://make.fun/bounty/u-coral-404-one-line-one-laugh-22f2c9f3

## Run it

```sh
python3 main.py
```

That writes the entry line to `/output/entry.txt`. An output path can also be given as the first argument, e.g. `python3 main.py /tmp/entry.txt`. No network, no randomness — the same line every run.
